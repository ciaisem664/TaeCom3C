Usage Statement and Disclaimer

This script is provided solely for personal study, research into Windows system mechanisms, and experiments with Steam data cleanup. The script’s actual behavior is to delete certain Steam game data, such as installed game files, download caches, and shader caches. It is designed not to delete game saves. However, game save locations vary: some saves may be stored in the game installation directory, Documents, AppData, the registry, or Steam Cloud. Therefore, the author does not guarantee that all save files will remain unaffected.

1. Conditions of Use
Use this script only on devices that you own or for which you have explicit written authorization.

It is strongly recommended that you run it only in a virtual machine, sandbox, or dedicated test machine, and that you create a snapshot before running it.

Before running the script, back up your Steam library, steamapps, userdata, Steam Cloud saves, and any game-related save files in Documents or AppData.

Create a system restore point and back up the registry before running the script.

Do not run this script on systems containing important data, production services, business environments, school or company devices, or other people’s accounts.

If you do not understand the risks of registry modification, file deletion, or Steam data structures, do not run this script.

2. Actual Behavior and Risk Notice
This script deletes certain Steam game data and may cause, but is not limited to, the following consequences:

Games may need to be redownloaded or reinstalled.

Game configurations, mods, Workshop content, caches, and settings may be lost.

The Steam library or game state may become abnormal.

Some games store local saves in the installation directory, which may be indirectly affected.

Steam Cloud synchronization may overwrite local saves or cause conflicts.

Behavior may vary across different Windows versions, Steam versions, and games.

Although the script is designed not to delete game saves, the statement that it “does not touch saves” should be understood as the author’s design intent and does not constitute an absolute guarantee for all games or all environments.
